# Stasis Syntax (VS Code)

This extension provides syntax highlighting for `*.stasis` files.

## Install (local, no build)

From the repo root:

- `powershell -ExecutionPolicy Bypass -File .\\scripts\\install_vscode_stasis_syntax.ps1`

Or manually copy `vscode-stasis-syntax/` to:

- `%USERPROFILE%\\.vscode\\extensions\\stasislang.stasis-syntax`
